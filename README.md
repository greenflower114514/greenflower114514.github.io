# greenflower114514.github.io

这是一个基于 GitHub Pages 和 Jekyll 的 Markdown 个人主页。

## 如何修改主页

主要编辑 `index.md`。

- 页面标题在文件开头的 `title` 字段里
- 正文内容直接用 Markdown 编写
- 想增加新页面时，可以新建例如 `about.md`、`projects.md`

## 仓库结构

- `_config.yml`: 站点配置
- `index.md`: 首页内容
- `README.md`: 维护说明
